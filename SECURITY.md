# Security Policy

## Reporting A Vulnerability

Do not open a public issue for a vulnerability, suspected secret, customer information, cloud
identifier, private-source detail, or exploit instructions.

Use GitHub private vulnerability reporting for this repository. Include only the minimum evidence
needed to reproduce the control-plane issue, redact operational identifiers, and do not attach
private application source or production data. If private reporting is unavailable, notify the
repository owner through an already-established private business channel and wait for a private
intake path.

## Scope

This repository contains public deployment policy and verification code only. Reports concerning the
private application, AWS account, customer records, carriers, shippers, telephony, email, payments,
or freight-software credentials must not be disclosed here.

No one is authorized to test against live infrastructure, bypass approvals, obtain credentials,
contact third parties, or perform denial-of-service testing through this policy.
